# Model Recommendation

- Inspect data length, seasonality, and nonlinearity indicators.
- Recommend candidate models with rationale and expected trade-offs.
- Define evaluation metrics (MAE, RMSE, R²) for comparison.
- Output a ranked model shortlist and selection justification.
