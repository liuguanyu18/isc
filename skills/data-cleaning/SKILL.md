# Data Cleaning

- Detect missing values and propose fill strategies (drop, mean/median, interpolation).
- Identify outliers with statistical rules (IQR/Z-score) and suggest corrections.
- Normalize or standardize numeric features with chosen method.
- Emit a cleaning report (issues found, actions taken, remaining risks).
